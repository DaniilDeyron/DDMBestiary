# DDM Bestiary

Общий иллюстрированный бестиарий для Foundry Virtual Tabletop v12.

## Установка

Manifest URL:

`https://github.com/DaniilDeyron/DDMBestiary/releases/latest/download/module.json`

1. В Foundry открой **Add-on Modules → Install Module**.
2. Вставь Manifest URL.
3. Нажми Install.
4. Включи **DDM Bestiary | Бестиарий** в настройках мира.

## Текущая версия 0.1.0

- Отдельная кнопка открытия на панели инструментов сцены.
- Книжная раскладка с категориями и записями.
- Тестовая запись «Делириумный выродок».
- Поля описания, поведения и особенностей.
- Две ячейки образцов с добавлением, удалением и drag & drop.
- Чек-лист исследования и расчёт процента.
- Сохранение записей в world settings.

## Важно для тестирования

Это ранний прототип. Для первого теста включи модуль в мире Foundry v12 и открой его кнопкой с книгой в панели инструментов сцены. Пока изменение записей и задач сохранено в общих настройках мира; расширенные права игроков, перенос предметов непосредственно в инвентарь и полноценная синхронизация действий игроков будут добавлены следующими итерациями.
