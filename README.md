# DDM Bestiary

Общий иллюстрированный бестиарий и книга рецептов для Foundry Virtual Tabletop v13.

## Установка

Manifest URL:

`https://raw.githubusercontent.com/DaniilDeyron/DDMBestiary/main/module.json`

1. В Foundry открой **Add-on Modules → Install Module**.
2. Вставь Manifest URL.
3. Нажми Install.
4. Включи **DDM Bestiary | Бестиарий** в настройках мира.

## Текущая версия 0.2.0

- Отдельная кнопка открытия книги на панели инструментов сцены и горячая клавиша Shift+B.
- Два самостоятельных раздела: **Бестиарий** и **Рецепты**.
- Бестиарий: иллюстрация, описание, поведение, особенности, образцы добычи и шкала изучения.
- Рецепты: изображение готового предмета, описание и список материалов с количеством.
- Добавление материалов вручную или перетаскиванием предметов из Foundry.
- Настройка мира «Игроки могут предлагать записи бестиария».
- Если настройка включена, игроки отправляют записи Мастеру на подтверждение. Мастер решает, добавлять ли их в общий бестиарий.
- Данные хранятся в настройках мира и общие для участников этого мира.

## Важно для тестирования

Это ранняя версия. Код проверен на синтаксические ошибки, но работу интерфейса необходимо проверить непосредственно в Foundry v13. После установки открой книгу кнопкой на панели сцены или сочетанием Shift+B. Создание и редактирование рецептов, изображений, материалов и исследовательских задач доступны Мастеру. Игрокам доступно предложение новых записей бестиария, если Мастер включил соответствующую настройку.
